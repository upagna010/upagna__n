# Hospital Analytics Dashboard

## Project Overview
An interactive Excel dashboard built to analyze 5000+ hospital patient records. This dashboard helps hospital management track key metrics like patient count, revenue, and satisfaction across different departments.

## Tools & Skills Used
- Microsoft Excel
- PivotTables
- Slicers for Dynamic Filtering
- KPI Cards
- Charts: Bar, Column, Pie, Donut
- Data Visualization

## Key Features
1. **Interactive Filters**: Filter by Department and Insurance Type
2. **6 Visualizations**: 
   - Patients by Department
   - Revenue by Department
   - Gender Distribution
   - Insurance Coverage
   - Admission Type Distribution
   - Satisfaction Score by Department
3. **KPI Cards**: Total Patients, Average Length of Stay, Average Treatment Cost, Total Revenue

## Key Insights
- Total Revenue: ₹2.65 Cr
- Average Length of Stay: 8 Days
- Highest Patient Count: Cardiology Department
- Highest Revenue: Gynecology Department

## How to Use
1. Download the `Hospital_Dashboard.xlsx` file
2. Use the slicers at the top to filter data by Department or Insurance
3. All charts and KPIs will update automatically
