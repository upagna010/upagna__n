# AI Tools ROI Calculator

### Project Overview
This project calculates Return on Investment (ROI) for various AI Tools. It helps businesses analyze Cost vs Time Saved vs Profitability.

### Key Features
- Cost Analysis of AI Tools
- Time Saved Calculation
- ROI Percentage & Profitability Dashboard
- Comparison of Different AI Tools

### Folder Contents
- Excel Calculator
- Dashboard (Power BI / Tableau)

### Tools Used
Excel, Power BI, Tableau
