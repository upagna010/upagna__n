### 📌 Project Overview
EV Pulse is a Power BI analytics project that tracks Electric Vehicle (EV) adoption, sales trends, and performance across India. The goal is to provide actionable insights for EV market growth.

### 📂 Dataset Details - `EV_Pulse_Data_Set.xlsx`
The dataset used in this project contains the following sheets & columns:
- **Vehicle Category:** 2-Wheeler, 3-Wheeler, 4-Wheeler, Bus
- **Vehicle Type:** Electric / Type of EV
- **State/Region Wise Data:** Sales count
- **Sales Volume / Count:** Number of vehicles registered
- **Date / Year:** Time-series analysis
- **Maker / Model Data:** (as per your Excel sheets)

> Data Source: Cleaned and structured from VAHAN / EV sales open data

### 🛠️ Tech Stack & Tools Used
- **Power BI:** Data Modeling, DAX Measures, Power Query
- **Excel:** Data Cleaning, Data Transformation
- **DAX:** Total Sales, YoY Growth %, Market Share
- **Visuals:** KPI Cards, Bar Chart, Line Chart, Donut Chart, Map Visual, Slicers

### 📊 Dashboard Insights & KPIs
1.  **Total EV Sales** - Overall adoption count
2.  **State-wise Top Performance** - Which states have highest EV adoption
3.  **Category-wise Split** - 2W vs 3W vs 4W adoption %
4.  **Yearly Growth Trend** - How EV sales grew year over year
5.  **Maker Analysis** - Top EV manufacturers
